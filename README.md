# Let's Travel - travel chatbot with accounts and demo hotel booking

A Flask website with an AI chatbot (Google Gemini, free tier) that chats about travel and can search and book hotels. People can sign up, their chats are saved, and they get a bookings page split into upcoming and previous stays.

- **Real:** the chatbot's answers (Gemini) and hotel names/locations/stars (OpenStreetMap, free).
- **Mock:** prices, room availability and bookings (generated by the code, stored in SQLite).

## Run it (Windows, Git Bash)

```bash
cd lets-travel
python -m venv venv
source venv/Scripts/activate        # Linux/Mac: source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env                # then open .env and fill in BOTH keys (see below)
python app.py
```

Open http://127.0.0.1:5000

In `.env` you need:

1. `GEMINI_API_KEY`: a free key from https://aistudio.google.com/apikey (Google account, no card).
2. `SECRET_KEY`: a long random string that signs the login cookie. Make one with
   `python -c "import secrets; print(secrets.token_hex(32))"`.
   If it is missing the site still runs, but everyone is logged out whenever the server restarts.

## Accounts, chats and bookings

| Feature | How it works |
|---|---|
| Sign up / log in | `/register` and `/login`. Passwords are stored only as salted hashes. Login lasts 14 days. |
| Booking | Needs a login. The booking is saved against the logged-in user, whether made on the Hotels page or through the chatbot. |
| My bookings | `/bookings` shows only your bookings: **Upcoming** (including a stay in progress) and **Previous** (already checked out). |
| Saved chats | Logged-in users' chats are saved. Open the chat and your latest conversation comes back. **New chat** starts a fresh one, **History** lists every old chat so you can reopen or delete it. |
| Chatting before login | A visitor can chat without an account (not saved). If they then log in or sign up, that chat moves into their account, so "log in, then say yes to book" works. |

After a server restart the chatbot's memory is rebuilt from the saved messages. Only the text is saved, so the bot may need to search for hotels again before booking.

## Files

| File | What it does |
|---|---|
| `app.py` | Flask server: pages, sign up / login, saved chats, `/chat` (sends your message to Gemini and gives it the two hotel tools). |
| `hotels.py` | `search_hotels()` and `book_hotel()`: the only two things the AI can do besides talk. |
| `db.py` | SQLite connection and tables: hotels, bookings, users, conversations, messages. Older databases are upgraded automatically. |
| `templates/` | `base.html` (nav + chat widget), `home.html`, `hotels.html`, `bookings.html`, `login.html`, `register.html`. |
| `static/` | `style.css`, `chat.js` (chat widget), `logo.svg`, `favicon.svg`. |
| `.env` | Your secret keys. Never share or commit it. |

## How a booking works

1. You log in, then ask: "Hotel in Goa, 20 to 23 Dec". Gemini calls `search_hotels("Goa", "2026-12-20", "2026-12-23")`.
2. `hotels.py` loads Goa hotels (OpenStreetMap, cached in `travel.db`), adds fake prices and rooms, returns the list.
3. Gemini shows the options. You pick one and give your name. Gemini asks you to confirm.
4. After "yes", Gemini calls `book_hotel(...)`. The server (not the AI) adds your user id, saves a row in `bookings`, and returns a `DEMO-XXXXXX` reference.

## Troubleshooting

- **"GEMINI_API_KEY is missing"**: create `.env` from `.env.example`, paste the key, restart.
- **Logged out after every restart**: set `SECRET_KEY` in `.env`.
- **"Model not found"**: set `GEMINI_MODEL` in `.env` to a Flash model name shown in Google AI Studio.
- **"Free Gemini limit reached"**: free tier is rate limited. Wait a minute.
- **Only invented hotel names appear**: OpenStreetMap was unreachable or had nothing for that place. Delete the cached hotels (see below) and retry with internet on.
- **Reset everything**: stop the server and delete `travel.db`. This also deletes all users, chats and bookings.
